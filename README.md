# Language settings

The profile stores `app_language` (`de`/`en`) separately from `learning_language` (currently German, English, or French). The central translation helper covers the navbar, profile language controls, and workspace analysis status, calls to the AI include both settings, and the remaining study-content copy stays German until the broader UI is localized.
